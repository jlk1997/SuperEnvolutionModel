# 通用证书

「通用」不是一句口号。同一套权重、同一具电脑身体、同一套学习规则，进入一个开发期间没打开过的行业包，不改代码，要同时满足路线图里的闸门 3。

## 行业包

开发包在 `evo/office/packs.py`：订单、报销、考勤、运单。它们可以随时看、随时改生成器。

留出包在 `evo/office/heldout.py`：成绩、诊所排班。这一对已经打开，作废。下一对封在 `evo/office/heldout_next.py`：借阅、仓库。开发流不能导入。入口是 `load_next_heldout`。不写明原因就打开，会直接拒绝。同一份封条文件打开过一次，再开也拒绝。

## 打开一次就作废

里程碑评测调用 `python -m evo heldout`。它把打开时间、原因和包名写进 `runs/heldout_seal.json`。这一对包从此只用于这一次判定。判定完，不管过没过，下一轮要换新的留出包，不能用同一对再调到通过。

调参只许改学习规则：写多快、何时睡、重放比例、分拣门槛。不许按留出包的字段名改生成器或提示词。

## 迁移增益

先用还没在开发包上更新过的模型做留出包，记下第一轮对错。再只在开发包上学习，然后用同一批留出题再考一次。第二次减第一次的配对区间要在 0 的上方。差值是 0，说明学到的都是本地槽，通用核是空的。

## 什么不许进通用核

一家部署的文件夹结构、接口字段原文、客户名和密钥留在本地槽，可以整块卸下。往外送的时候先把这些字符串换成占位符，再用假数据重做同类任务。导出文本里还找得到私有字符串，导出失败，权重不离开这台机器。
