# 文献定位

这篇是可塑性进化这条线的坐标，不是综述。目的是把「别人已经做了什么」和「我们要证的那三件事」分开。引用在投稿前还要对一遍原文页码；下面的归属按这些工作公开的主张来写，不替它们报我们没核对过的数字。

我们要证的只有三件事，而且要在预训练语言模型上证：

1. 学习能力本身会在部署过程中变强。新任务族达到合格所需的交互次数随时间下降。
2. 这种变强可以遗传：传给下一代，或者换一个基座之后还在。
3. 种群层面看得到鲍德温效应和遗传同化。学习引导进化；高频技能会沉淀成出生就会的能力，低频技能仍然靠当场学。

下面每一行都回答同一个问题：这项工作动的是什么，它有没有碰到这三件事。

| 工作 | 它实际在优化什么 | 学习能力会不会变强 | 能不能遗传 | 和我们的差别 |
| --- | --- | --- | --- | --- |
| SEAL（Zweiger 等，2025） | 模型生成自己的微调数据和训练指令，再用强化学习挑有用的自编辑 | 不测。它改进的是一次任务上的适应 | 自编辑不作为可继承的学习规则 | 学的是「这次写什么」，不是「以后怎么学」 |
| Absolute Zero（Zhao 等，2025） | 自己出题、自己解题，用代码执行器打分 | 不测跨任务族的加速 | 无 | 奖励信号和我们一样靠执行器，但没有代际，也没有可塑性 |
| STaR / ReST / ReST-EM | 只保留做对的推理或样本，再监督训练 | 不测 | 无 | 我们夜里的成功样本更新就是这一类，已经做过，不够 |
| TTT 层（Sun 等） | 测试时用自监督损失改一层权重 | 架构里带学习，但是固定算法 | 无 | 要改架构并预训练。学习规则是人手写死的 |
| Titans（Behrouz 等，Google） | 用「惊讶度」写入神经记忆 | 记忆在变，学习规则不变 | 无 | 快记忆机制可借鉴，不是进化 |
| Nested Learning / HOPE（Behrouz、Mirrokni 等，2025） | 多层时间尺度的记忆和学习 | 多层更新同时发生 | 无 | 和我们的快/中/慢同方向，但是设计出来的，不是进化出来的 |
| ATLAS（测试时记忆，Titans 一系后续） | 在上下文上学习如何记忆 | 规则固定 | 无 | 仍是单一个体、一次生命周期 |
| Gated DeltaNet（Yang 等；Qwen3.5 的混合层） | 门控 delta 规则作为序列层 | 状态能跨步保留 | 无 | 我们把它当作快时间尺度的现成器官，不把它再说成新架构 |
| Darwin Gödel Machine（Zhang 等，2025） | 智能体改自己的 Python 代码，用实验筛选 | 改的是外部代码 | 代码库可以留下 | 体重没有进权重。脚手架还在 |
| AlphaEvolve（DeepMind，2025） | 进化搜索程序，发现算法 | 搜索的是答案程序 | 无模型遗传 | 进化的是产物，不是学习者 |
| Voyager（Wang 等） | 技能库存成代码，碰到新任务再检索 | 库在变大 | 库可拷贝 | 典型的外挂记忆。我们的闸门要求权重学习超过这种做法 |
| Evolutionary Model Merge（Sakana，Akiba 等，2024） | 进化搜索合并系数 | 一次性离线合并 | 合并结果是一个检查点 | 不在部署中持续学 |
| ES at Scale（Qiu 等，2025，*Evolution Strategies at Scale*） | 用进化策略直接微调十亿级语言模型的权重 | 不测「越学越快」 | 无分离的基因组 | 证明了 ES 打得动大模型。我们搜的是学习规则，不是权重 |
| Text-to-LoRA | 由文本描述生成适配器 | 一次性生成 | 无 | 离线的适配器生成 |
| Differentiable Plasticity（Miconi 等，2018） | 把 Hebb 可塑性系数和权重一起训练 | 可塑性可学 | 在小网络里可以 | 没上预训练语言模型，也没有工具执行器 |
| 进化 Hebb 规则（Najarro、Risi，2020） | 进化局部学习规则 | 规则可进化 | 规则可遗传 | 同上，尺度和任务都不同 |
| OML / ANML（Javed、White，2019；Beaulieu 等，2020） | 元学习一个能在线学、又少遗忘的网络 | 元测试时学得动 | 元参数可迁移 | 小网络上的分类。没有「出生适应度不升、学后适应度升」这种种群实验 |
| Hinton、Nowlan，1987 | 学习平滑适应度地貌，进化因此找得到先天解 | 这是效应本身 | 基因编码的是性状，不是大数据权重 | 我们把这个实验搬到语言模型的学习规则上 |
| Waddington 遗传同化 | 原先必须靠发育（学习）才出现的性状，后来变成先天的 | — | 高频环境里的性状被写进基因组 | 我们的高频任务族对低频任务族 |
| 互补学习系统（McClelland 等，1995） | 海马体快学，新皮层慢固化 | 时间尺度是设计出来的 | 无 | 如果我们的可塑性图自己长成「快 delta、慢 MLP」，这是被重新发现，不是被写死 |

## 空白

上表里没有一行同时满足这四条：

- 基座是预训练语言模型，训练时不动主干。
- 进化搜索的对象是可塑性（写哪一层、哪个位置、哪一档时间尺度、多快），不是权重，也不是外部代码。
- 适应度看的是新任务族上的学习曲线，不是当晚那几道练习题。
- 实验能把鲍德温、拉马克、达尔文三种继承分开。

这就是这条线的位置。已有系统里的 SFT、反向 KL、七个超参数的变异，分别落在 ReST、上下文蒸馏、和一次很小的随机搜索里，不在这个空白里。

## 不声称的事

- 不声称已经在语言模型上观察到鲍德温效应。机制模型（可塑学习者的种群）里的曲线是效应的存在性证明，语言模型上的确认实验另记。
- 不声称进化策略微调大模型是我们先做的。Qiu 等已经做了权重上的 ES。
- 不声称快权重或 delta 规则是新的。我们只用它当基因组里的一个开关。
