# 蚁算命名约定

更新日期：2026-10-18（Asia/Shanghai）

| 名称 | 角色 | 说明 |
| --- | --- | --- |
| **蚁算模型** | 对外产品 / 模型名 | 上海蚁算的使用驱动进化模型；中文对外主名 |
| **Ant Compute** | 英文产品名 | 与「蚁算」对应；对外材料可用 |
| **Envolution** | 引擎 / 仓库代号 | 代码、配置、实验脚本、内部引擎名可保留；不等于产品品牌 |
| **evo** | Python 包名 | 仓库内实现包；不变 |

规则：

1. 对用户、投资人、文档首屏：说「蚁算模型」。
2. 对工程、commit、模块路径：可继续写 Envolution / evo。
3. 不把 Envolution 口头说成「我们卖的模型名」；不把蚁算说成「只是个项目文件夹」。
4. Gate 证据、CLAIM 文案里「dual / agent / dissolve」等技术词保留英文术语，旁注中文。
